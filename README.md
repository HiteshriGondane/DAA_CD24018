# 🚀 Design & Analysis of Algorithms (DAA) – Practical List  
📚 *Session 2026-27 | S. B. Jain Institute of Technology, Nagpur*  

---

## 🎯 Course Objective  
This course enables students to design and analyze algorithms in terms of efficiency and correctness, highlighting problem-solving techniques for efficient algorithm design.

---

## ✅ Course Outcomes  
- **CO1:** Apply traversal & search techniques on graphs; solve with backtracking & approximation.  
- **CO2:** Analyze time & space complexity, determine algorithmic performance.  
- **CO3:** Evaluate data structures & paradigms for solving problems.  
- **CO4:** Create efficient algorithms for moderately complex computational problems.  

---

## 🧪 Practical List  

<details>
<summary>🔍 Pre-Lab</summary>
Analyse the time and space complexity of an algorithm that generates all prime numbers up to `n`. Perform empirical comparisons for inputs: 100, 1000, 10000, 100000.
</details>

<details>
<summary>⚡ Practical 1 – Quick Sort Logs</summary>
Sort massive unsorted log files (Unix timestamps) using **Quick Sort** to trace server crash events.
</details>

<details>
<summary>📜 Practical 2 – Binary Search Manuscripts</summary>
Locate the **first occurrence** of an Archive ID efficiently using **Binary Search**.
</details>

<details>
<summary>🛰️ Practical 3 – Strassen’s Matrix Multiplication</summary>
Perform **4×4 matrix multiplication** using Strassen’s Divide & Conquer algorithm.
</details>

<details>
<summary>🌐 Practical 4 – Kruskal’s MST</summary>
Connect cities with minimum fiber installation cost using **Minimum Spanning Tree**.
</details>

<details>
<summary>🚑 Practical 5 – Dijkstra’s Shortest Path</summary>
Compute shortest ambulance routes in Mumbai using **Dijkstra’s Algorithm**.
</details>

<details>
<summary>📦 Practical 6 – Travelling Salesman Problem</summary>
Optimize drone delivery routes using **Dynamic Programming** for TSP.
</details>

<details>
<summary>🧬 Practical 7 – Longest Common Subsequence</summary>
Find LCS between DNA sequences to identify evolutionary patterns.
</details>

<details>
<summary>💱 Practical 8 – Bellman-Ford Arbitrage</summary>
Detect negative weight cycles in currency exchange graphs using **Bellman-Ford**.
</details>

<details>
<summary>📡 Practical 9 – N-Queens Problem</summary>
Place N antennas on an N×N grid avoiding row, column, and diagonal conflicts.
</details>

<details>
<summary>👥 Practical 10 – Depth First Search</summary>
Trace social media post reach using **DFS** on directed graphs.
</details>
